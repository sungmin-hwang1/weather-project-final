**제작자:** 황성민 (24017103)  
**배포 URL:** https://vercel.com/sungmin-hwang1s-projects/weather-project-final  
**API:** OpenWeatherMap

---

## 📌 프로젝트 개요
HTML, CSS, JavaScript(바닐라 JS)를 활용하여 동적으로 동작하는 **날씨 예보 웹사이트**입니다.  
도시명을 검색하면 현재 온도, 습도, 풍속, 날씨 아이콘, 3일 예보를 실시간으로 보여줍니다.

또한 **섭씨/화씨 단위 전환**, **최근 검색 도시 저장(localStorage)**,  
**추천 옷차림 출력** 기능을 포함하고 있습니다.

---

## 🎯 개발 목적 (학습 목표)
- fetch()로 API 호출 및 JSON 데이터 파싱
- DOM 요소 동적 업데이트
- localStorage를 활용한 데이터 저장
- Mobile-first 반응형 UI 설계
- Vercel을 이용한 실제 웹 배포 및 운영 경험

## 💡 주요 기능

### ✔ 필수 기능
- 도시 검색 및 Enter 입력 대응
- 현재 날씨 표시 (온도, 체감온도, 습도, 풍속, 아이콘, 설명)
- 3일 예보 카드 표시 (12시 기준 데이터)
- 섭씨 ↔ 화씨 변환 버튼
- 잘못된 도시 검색 시 오류 메시지 처리
- 최근 검색 도시 저장 (최대 5개, 버튼 자동 생성)

### ✔ 확장 기능 (개인 기능)
- **날씨 기반 옷차림 추천**
  - 0℃ 이하: 패딩 + 장갑 + 목도리
  - 0~10℃: 코트/니트
  - 10~20℃: 가벼운 자켓
  - 20~28℃: 반팔/얇은 긴팔
  - 28℃ 이상: 민소매 + 수분 섭취 추천
